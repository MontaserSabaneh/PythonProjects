# Warehouse Object Triage

## Description
This project is a simple Python program that reads warehouse objects from a JSON file, classifies them based on their properties, filters objects by category, stores them using an Inventory class, and prints a summary.

## Features
- Read objects from a JSON file.
- Classify objects (Hot, Heavy, Round, Normal).
- Filter objects by category.
- Store objects using an Inventory class.
- Handle missing data using try/except.
- Display a warehouse summary.

## How to Run
1. Open the project.
2. Run the `main.py` file.
3. The program will display the classified objects and the warehouse summary.
